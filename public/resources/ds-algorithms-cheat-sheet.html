Prefix Sum + HashMap

  • Range sum: sum(l,r) = pre[r+1] - pre[l]
  • Subarray sum = K: at index j look up pre - K in a map of earlier prefixes
  • 2D prefix: P[i][j] = a + P[i-1][j] + P[i][j-1] - P[i-1][j-1]
  • Same idea with remainder: subarray sum divisible by K → store pre % K
  • Zero-sum / balance: map 0→-1, 1→+1 (Contiguous Array)

Merge sort O(n log n) time, O(n) space, stable
void mergeSort(int[] a, int l, int r) {          // sorts a[l..r]
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(a, l, m); mergeSort(a, m + 1, r);
    int[] tmp = new int[r - l + 1];
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r) tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];   // <= keeps it stable
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, l, tmp.length);
}
Quick sort avg O(n log n), worst O(n^2), O(log n) stack
void quickSort(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1); quickSort(a, p + 1, hi);
}
int partition(int[] a, int lo, int hi) {            // Lomuto, random pivot
    swap(a, lo + new Random().nextInt(hi - lo + 1), hi);
    int pivot = a[hi], i = lo;
    for (int j = lo; j < hi; j++) if (a[j] < pivot) swap(a, i++, j);
    swap(a, i, hi);
    return i;
}
Quickselect (Kth element without full sort)
// Quickselect: kth smallest in O(n) average (use partition above)
int select(int[] a, int lo, int hi, int k) {        // k is 0-based
    int p = partition(a, lo, hi);
    if (p == k) return a[p];
    return p < k ? select(a, p + 1, hi, k) : select(a, lo, p - 1, k);
}
Heap sort O(n log n), O(1) space, not stable
void heapSort(int[] a) {
    int n = a.length;
    for (int i = n / 2 - 1; i >= 0; i--) sift(a, n, i);     // build max-heap O(n)
    for (int e = n - 1; e > 0; e--) { swap(a, 0, e); sift(a, e, 0); }
}
void sift(int[] a, int n, int i) {
    while (true) {
        int l = 2*i + 1, r = l + 1, big = i;
        if (l < n && a[l] > a[big]) big = l;
        if (r < n && a[r] > a[big]) big = r;
        if (big == i) return;
        swap(a, i, big); i = big;
    }
}
Counting sort O(n+k), stable
int[] countingSort(int[] a, int k) {                 // values in 0..k
    int[] cnt = new int[k + 1], out = new int[a.length];
    for (int x : a) cnt[x]++;
    for (int i = 1; i <= k; i++) cnt[i] += cnt[i - 1];     // prefix: end position of each value
    for (int i = a.length - 1; i >= 0; i--) out[--cnt[a[i]]] = a[i];   // backwards = stable
    return out;
}

// Directed cycle via DFS colours: 0 = new, 1 = on current path, 2 = done
boolean hasCycle(int u, int[] state) {
    state[u] = 1;
    for (int v : g.get(u)) {
        if (state[v] == 1) return true;                    // back edge

Union-Find (Disjoint Set) & MST

  • Operations: make(x), find(x), union(x, y). Optimisations: path compression + union by rank/size → near O(1) amortised (inverse Ackermann).
  • Use cases: Number of Islands II, Redundant Connection, Accounts Merge, Number of Provinces, Kruskal's MST, graph valid tree (E = V-1 and one component).
Union-Find
int[] p, rk;                                           // p[i] = i initially
int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }   // path compression
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return false;                        // already connected -> cycle edge
    if (rk[ra] < rk[rb]) { int t = ra; ra = rb; rb = t; }
    p[rb] = ra;                                        // attach shorter under taller
    if (rk[ra] == rk[rb]) rk[ra]++;
    return true;
}
Kruskal O(E log E)
// Kruskal MST: sort edges by weight, add if it joins two components
Arrays.sort(edges, (a, b) -> Integer.compare(a[2], b[2]));
int cost = 0, used = 0;
for (int[] e : edges)
    if (union(e[0], e[1])) { cost += e[2]; if (++used == n - 1) break; }

Prim's MST (when to prefer)

  • Grow one tree: min-heap of (weight, node) edges leaving the tree.
  • O(E log V). Better for dense graphs; Kruskal better for sparse / edge lists.

Strongly Connected Components

  • Kosaraju: (1) DFS, push nodes by finish time; (2) reverse the graph; (3) DFS in reverse finish order, each tree = one SCC.
  • Tarjan: single DFS with low-link values and a stack. O(V+E).
  • Use: dependency analysis, 2-SAT, condensing a graph into a DAG.
Watch out. Marking visited when POLLING (not enqueuing) → duplicates in queue. Using BFS for weighted shortest path. Dijkstra with negative edges. Forgetting the visited set → infinite loop. Missing grid bounds checks. Recursive DFS overflow on deep graphs (use an explicit stack).

void backtrack(int[] a, int start, List<Integer> path, List<List<Integer>> res) {
    res.add(new ArrayList<>(path));                  // COPY: path keeps mutating
    for (int i = start; i < a.length; i++) {
        path.add(a[i]);                              // choose
        backtrack(a, i + 1, path, res);              // explore
        path.remove(path.size() - 1);                // un-choose
    }
}
Permutations O(n * n!)
void perm(int[] a, boolean[] used, List<Integer> path, List<List<Integer>> res) {
    if (path.size() == a.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < a.length; i++) {
        if (used[i]) continue;
        used[i] = true; path.add(a[i]);
        perm(a, used, path, res);
        path.remove(path.size() - 1); used[i] = false;
    }
}
Combination sum
// Combination Sum (reuse allowed). Sort first to prune.
void comb(int[] a, int start, int remain, List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < a.length && a[i] <= remain; i++) {      // prune
        path.add(a[i]);
        comb(a, i, remain - a[i], path, res);                       // i: same element again
        path.remove(path.size() - 1);
    }
}
N-Queens (pruning)
// N-Queens: O(1) conflict checks with three boolean arrays
boolean[] col = new boolean[n], d1 = new boolean[2*n], d2 = new boolean[2*n];
void place(int r) {
    if (r == n) { count++; return; }
    for (int c = 0; c < n; c++) {
        if (col[c] || d1[r - c + n] || d2[r + c]) continue;         // prune
        col[c] = d1[r - c + n] = d2[r + c] = true;
        place(r + 1);
        col[c] = d1[r - c + n] = d2[r + c] = false;                 // undo
    }
}
Grid backtracking
boolean exist(char[][] b, String w, int r, int c, int i) {            // Word Search
    if (i == w.length()) return true;
    if (r < 0 || c < 0 || r >= b.length || c >= b[0].length || b[r][c] != w.charAt(i)) return false;
    char t = b[r][c]; b[r][c] = '#';                                   // mark visited
    boolean ok = exist(b, w, r+1, c, i+1) || exist(b, w, r-1, c, i+1)
              || exist(b, w, r, c+1, i+1) || exist(b, w, r, c-1, i+1);
    b[r][c] = t;                                                       // restore
    return ok;
}

Optimisations

  • Prune early: stop branches that cannot succeed (sum exceeded, column attacked).
  • Sort to enable pruning and duplicate skipping.
  • Visited / used[] to avoid repeats.
  • Memoise when states repeat (then it is DP).

Common mistakes

  • Missing or unreachable base case → StackOverflowError
  • Adding path without copying
  • Forgetting the un-choose step
  • Not moving toward the base case (infinite recursion)
  • Modifying shared state without restoring it
  • Exponential recursion where DP applies

  • Smallest meaningful input: dp[0]=0 / 1
  • Grid: first row / column
  • Knapsack: dp[w][0]=0, empty strings for LCS / edit distance
  • Counting: empty choice counts as 1 way

  • Wrong state definition or missing dimension
  • Wrong transition / off-by-one (i-1 vs i)
  • Iterating in wrong order (knapsack direction!)
  • Mixing 0/1 with unbounded logic
  • int overflow where long is needed
  • Forgetting base cases or edge cases

  • Row i depends only on row i-1 → two rows or one row
  • 1D DP depending on 2 previous → two variables

LRU Cache (the interview version)
class LRUCache {                                              // manual: HashMap + doubly linked list
    class N { int k, v; N p, n; }
    Map<Integer, N> m = new HashMap<>(); N head = new N(), tail = new N(); int cap;
    LRUCache(int c) { cap = c; head.n = tail; tail.p = head; }
    int get(int k) { N x = m.get(k); if (x == null) return -1; unlink(x); front(x); return x.v; }
    void put(int k, int v) {
        N x = m.get(k);
        if (x != null) { x.v = v; unlink(x); front(x); return; }
        if (m.size() == cap) { N lru = tail.p; unlink(lru); m.remove(lru.k); }   // evict LRU
        x = new N(); x.k = k; x.v = v; m.put(k, x); front(x);
    }
    void unlink(N x) { x.p.n = x.n; x.n.p = x.p; }
    void front(N x)  { x.n = head.n; x.p = head; head.n.p = x; head.n = x; }
}

Variable, longest (max-frequency trick)
// VARIABLE, LONGEST: Longest Repeating Character Replacement (at most K changes)
int[] cnt = new int[26]; int maxF = 0, best = 0;
for (int l = 0, r = 0; r < s.length(); r++) {
    maxF = Math.max(maxF, ++cnt[s.charAt(r) - 'A']);   // most frequent char seen in the window
    while (r - l + 1 - maxF > k) cnt[s.charAt(l++) - 'A']--;   // invalid: needs more than K changes
    best = Math.max(best, r - l + 1);                  // record AFTER shrinking
}
Variable, shortest
// VARIABLE, SHORTEST: Minimum Size Subarray Sum (sum >= target, positives only)
int sum = 0, best = Integer.MAX_VALUE;
for (int l = 0, r = 0; r < a.length; r++) {
    sum += a[r];
    while (sum >= target) {                            // valid: try to make it smaller
        best = Math.min(best, r - l + 1);              // record INSIDE the loop
        sum -= a[l++];
    }
}

Counting (at-most trick)
// COUNTING: Subarrays with K Different Integers  = atMost(K) - atMost(K-1)
int atMost(int[] a, int k) {
    Map<Integer, Integer> cnt = new HashMap<>(); int res = 0;
    for (int l = 0, r = 0; r < a.length; r++) {
        cnt.merge(a[r], 1, Integer::sum);
        while (cnt.size() > k) { if (cnt.merge(a[l], -1, Integer::sum) == 0) cnt.remove(a[l]); l++; }
        res += r - l + 1;                              // every subarray ending at r that starts in [l, r]
    }
    return res;
}
// answer: atMost(a, K) - atMost(a, K - 1)

// COUNTING with a product: Subarray Product Less Than K (positives)
if (k <= 1) return 0;

for (int l = 0, r = 0; r < a.length; r++) {
    prod *= a[r];
    while (prod >= k) prod /= a[l++];                  // shrink while TOO BIG

// Reverse nodes left..right (1-indexed) in one pass
ListNode dummy = new ListNode(0); dummy.next = head;
ListNode pre = dummy;
for (int i = 1; i < left; i++) pre = pre.next;           // node BEFORE the sublist
ListNode cur = pre.next;
for (int i = 0; i < right - left; i++) {                 // pull the next node to the front

    cur.next = nxt.next;
    nxt.next = pre.next;
    pre.next = nxt;
}

Reverse in k-groups
// Reverse every k nodes (recursive); fewer than k left stays as is
ListNode reverseKGroup(ListNode head, int k) {
    ListNode node = head; int cnt = 0;
    while (node != null && cnt < k) { node = node.next; cnt++; }
    if (cnt < k) return head;
    ListNode prev = reverseKGroup(node, k), cur = head;     // prev = already-processed rest
    while (cnt-- > 0) { ListNode nx = cur.next; cur.next = prev; prev = cur; cur = nx; }
    return prev;
}

// Longest Palindromic Subsequence  O(n^2)   (equals LCS of s and reverse(s))
int[][] dp = new int[n][n];

Swap, reverse, rotate (two pointers)

★★★★★ L1 Foundationstype in ≤ 1 min
Builds onnothing: start here

The smallest two-pointer program. Swap is reused by every in-place sort below.

Interview-ready code
void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }

void reverse(int[] a, int i, int j) {              // reverse a[i..j] in place
    while (i < j) swap(a, i++, j--);               // pointers walk toward each other
}

void rotate(int[] a, int k) {                      // rotate right by k, O(n) time, O(1) space
    k %= a.length;                                 // k can exceed the length
    reverse(a, 0, a.length - 1);                   // 1 2 3 4 5 -> 5 4 3 2 1
    reverse(a, 0, k - 1);                          // first k back in order
    reverse(a, k, a.length - 1);                   // the rest back in order
}

boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] cnt = new int[26];                       // fixed alphabet: array beats HashMap
    for (int i = 0; i < s.length(); i++) {
        cnt[s.charAt(i) - 'a']++;                  // +1 for s

    return true;
}

Prefix sum (+ HashMap count)

★★★★★ L1 Foundationstype in ≤ 2 min
Builds on#2 Frequency counting (int[26] and HashMap)

Turns any range-sum question into O(1) lookups; with a map it counts subarrays in O(n).

int[] prefix(int[] a) {                            // pre[i] = a[0] + ... + a[i-1], pre[0] = 0
    int[] pre = new int[a.length + 1];
    for (int i = 0; i < a.length; i++) pre[i + 1] = pre[i] + a[i];
    return pre;
}
int rangeSum(int[] pre, int l, int r) {            // sum of a[l..r] in O(1)
    return pre[r + 1] - pre[l];
}

int subarraySum(int[] a, int k) {                  // number of subarrays summing to k (negatives OK)
    Map<Integer, Integer> seen = new HashMap<>();  // prefix sum -> how many times seen
    seen.put(0, 1);                                // the empty prefix
    int sum = 0, count = 0;
    for (int x : a) {
        sum += x;
        count += seen.getOrDefault(sum - k, 0);    // an earlier prefix that leaves exactly k
        seen.merge(sum, 1, Integer::sum);
    }
    return count;
}

Builds onnothing: start here

One template that also gives exact match, first / last position, insert position and search-on-answer.

int lowerBound(int[] a, int t) {                   // first index with a[i] >= t, or a.length
    int lo = 0, hi = a.length;                     // the answer is always inside [lo, hi]
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;              // no int overflow
        if (a[mid] >= t) hi = mid;                 // mid may be the answer: keep it
        else lo = mid + 1;                         // mid is too small: drop it
    }
    return lo;
}

int search(int[] a, int t) {                       // exact match built on lowerBound
    int i = lowerBound(a, t);
    return i < a.length && a[i] == t ? i : -1;
}

Merge two sorted ranges

★★★★★ L2 Sorting & selectiontype in ≤ 2 min
Builds on#5 Two pointers on a sorted array

The heart of merge sort, merging lists, K-way merge and counting inversions.

Interview-ready code
// merge sorted a[lo..mid] and a[mid+1..hi]; tmp has the same length as a
void merge(int[] a, int[] tmp, int lo, int mid, int hi) {
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++]; // <= keeps equal elements in order (stable)
    while (i <= mid) tmp[k++] = a[i++];            // copy what is left of either run
    while (j <= hi)  tmp[k++] = a[j++];
    for (k = lo; k <= hi; k++) a[k] = tmp[k];      // copy back
}

Quick sort (partition + 3-way)

★★★★★ L2 Sorting & selectiontype in ≤ 3 min
Builds on#1 Swap, reverse, rotate (two pointers)

Partition is reused by quickselect; the 3-way version stays fast when there are many duplicates.

Interview-ready code
Random rnd = new Random();

int partition(int[] a, int lo, int hi) {           // Lomuto: returns the pivot's final index
    swap(a, lo + rnd.nextInt(hi - lo + 1), hi);    // random pivot moved to the end
    int pivot = a[hi], i = lo;                     // invariant: a[lo..i-1] < pivot
    for (int j = lo; j < hi; j++)
        if (a[j] < pivot) swap(a, i++, j);
    swap(a, i, hi);                                // pivot lands between the two parts
    return i;
}

void quickSort(int[] a, int lo, int hi) {          // 3-way (Dutch flag): great with duplicates
    if (lo >= hi) return;
    int pivot = a[lo + rnd.nextInt(hi - lo + 1)];
    int lt = lo, i = lo, gt = hi;                  // [lo,lt) < p, [lt,i) == p, (gt,hi] > p
    while (i <= gt) {
        if (a[i] < pivot) swap(a, lt++, i++);
        else if (a[i] > pivot) swap(a, i, gt--);   // do not advance i: new a[i] unchecked
        else i++;
    }
    quickSort(a, lo, lt - 1);                      // equal block is already in place
    quickSort(a, gt + 1, hi);
}

Heap: sift down and heap sort

★★★★★ L2 Sorting & selectiontype in ≤ 3 min
Builds on#1 Swap, reverse, rotate (two pointers)

Shows how PriorityQueue works inside; heap sort is O(n log n) with O(1) extra space.

Interview-ready code
void heapSort(int[] a) {
    int n = a.length;
    for (int i = n / 2 - 1; i >= 0; i--) siftDown(a, i, n);  // build a max-heap bottom-up: O(n)
    for (int end = n - 1; end > 0; end--) {
        swap(a, 0, end);                           // current max goes to its final slot
        siftDown(a, 0, end);                       // repair the heap on a[0..end-1]
    }
}
void siftDown(int[] a, int i, int n) {
    while (2 * i + 1 < n) {
        int c = 2 * i + 1;                         // left child
        if (c + 1 < n && a[c + 1] > a[c]) c++;     // pick the larger child
        if (a[i] >= a[c]) return;                  // heap property holds
        swap(a, i, c);
        i = c;
    }
}

void countingSort(int[] a) {                       // values in a small range, may be negative
    if (a.length == 0) return;
    int min = a[0], max = a[0];
    for (int x : a) { min = Math.min(min, x); max = Math.max(max, x); }

        ListNode next = cur.next;                  // 1. save the rest of the list

}

Merge lists + merge sort on a list

★★★★★ L3 Linear structurestype in ≤ 3 min
Builds on#7 Merge two sorted ranges#14 Fast and slow pointers

Combines snippets 7 and 14: split at the middle, sort both halves, merge.

ListNode mergeLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;   // dummy head: no special first node
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;               // attach the leftover run
    return dummy.next;
}

ListNode sortList(ListNode head) {                 // O(n log n), O(log n) stack
    if (head == null || head.next == null) return head;
    ListNode slow = head, fast = head.next;        // slow stops at the FIRST middle
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    ListNode right = slow.next;
    slow.next = null;                              // cut into two lists
    return mergeLists(sortList(head), sortList(right));
}

int[] windowMax(int[] a, int k) {
    int[] res = new int[a.length - k + 1];
    Deque<Integer> dq = new ArrayDeque<>();        // indices; values decreasing front to back
    for (int i = 0; i < a.length; i++) {
        if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();   // left the window
        while (!dq.isEmpty() && a[dq.peekLast()] <= a[i]) dq.pollLast(); // can never be the max
        dq.offerLast(i);
        if (i >= k - 1) res[i - k + 1] = a[dq.peekFirst()];             // front = window max
    }
    return res;
}

List<List<Integer>> levels(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new ArrayDeque<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();                       // freeze: nodes on this level only
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        res.add(level);                            // right view = level.get(level.size() - 1)
    }
    return res;
}

class Trie {
    private final Trie[] next = new Trie[26];      // one child per letter
    private boolean end;                           // a word ends here

    void insert(String w) {
        Trie node = this;
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            if (node.next[i] == null) node.next[i] = new Trie();
            node = node.next[i];
        }
        node.end = true;
    }
    boolean search(String w) { Trie n = find(w); return n != null && n.end; }
    boolean startsWith(String p) { return find(p) != null; }

    private Trie find(String s) {                  // walk the path, null if it breaks
        Trie node = this;
        for (char c : s.toCharArray()) {

int shortestPath(int[][] g) {                      // 0 = open, 1 = wall, 4-directional
    int m = g.length, n = g[0].length;
    if (g[0][0] == 1 || g[m - 1][n - 1] == 1) return -1;
    int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};    // add 4 diagonals for 8-directional problems
    boolean[][] seen = new boolean[m][n];
    Queue<int[]> q = new ArrayDeque<>();
    q.offer(new int[]{0, 0});
    seen[0][0] = true;
    for (int steps = 0; !q.isEmpty(); steps++) {
        for (int sz = q.size(); sz > 0; sz--) {    // one BFS layer = one step
            int[] cur = q.poll();
            if (cur[0] == m - 1 && cur[1] == n - 1) return steps;
            for (int[] d : dirs) {
                int r = cur[0] + d[0], c = cur[1] + d[1];
                if (r < 0 || c < 0 || r >= m || c >= n || g[r][c] == 1 || seen[r][c]) continue;
                seen[r][c] = true;                 // mark on enqueue, not on poll
                q.offer(new int[]{r, c});
            }
        }
    }
    return -1;                                     // target unreachable
}

class DSU {
    private final int[] parent, rank;
    int count;                                     // number of components

    DSU(int n) {
        parent = new int[n]; rank = new int[n]; count = n;
        for (int i = 0; i < n; i++) parent[i] = i; // everyone starts alone
    }
    int find(int x) {                              // path compression
        return parent[x] == x ? x : (parent[x] = find(parent[x]));
    }
    boolean union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;                // already connected: edge makes a cycle
        if (rank[ra] < rank[rb]) { int t = ra; ra = rb; rb = t; }
        parent[rb] = ra;                           // attach the shorter tree under the taller
        if (rank[ra] == rank[rb]) rank[ra]++;
        count--;
        return true;
    }
}

int[] dijkstra(int n, int[][] edges, int src) {    // edge {u, v, w}, directed
    List<List<int[]>> g = new ArrayList<>();
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] e : edges) g.get(e[0]).add(new int[]{e[1], e[2]});
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
    pq.offer(new int[]{src, 0});                   // {node, distance so far}
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], d = cur[1];
        if (d > dist[u]) continue;                 // stale: a shorter path was already found
        for (int[] e : g.get(u)) {
            int v = e[0], nd = d + e[1];
            if (nd < dist[v]) { dist[v] = nd; pq.offer(new int[]{v, nd}); }   // relax
        }
    }
    return dist;                                   // MAX_VALUE = unreachable
}

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();   // value -> index, for numbers already passed
        for (int i = 0; i < nums.length; i++) {

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);                                       // sorting enables two pointers + dedupe
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) break;                              // smallest value positive: no zero sum left
            if (i > 0 && nums[i] == nums[i - 1]) continue;       // skip duplicate anchors
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < 0) l++;                                // need a bigger sum
                else if (sum > 0) r--;                           // need a smaller sum
                else {

                    while (l < r && nums[l] == nums[l - 1]) l++; // skip duplicate seconds
                    while (l < r && nums[r] == nums[r + 1]) r--; // skip duplicate thirds
                }
            }
        }
        return res;

class Solution {

        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));   // by start

            int[] next = intervals[i];
            if (next[0] <= cur[1]) cur[1] = Math.max(cur[1], next[1]);   // overlap: extend

class Solution {
    public int search(int[] nums, int target) {
        int lo = 0, hi = nums.length - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;                 // no overflow
            if (nums[mid] == target) return mid;
            if (nums[lo] <= nums[mid]) {                  // left half [lo, mid] is sorted
                if (nums[lo] <= target && target < nums[mid]) hi = mid - 1;
                else lo = mid + 1;
            } else {                                      // right half [mid, hi] is sorted
                if (nums[mid] < target && target <= nums[hi]) lo = mid + 1;
                else hi = mid - 1;
            }
        }
        return -1;
    }
}
Key insightAt every step one half is sorted. Check whether the target lies inside that sorted half.
TrapUse <= in nums[lo] <= nums[mid] so a two-element range picks the correct half.

    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> Integer.compare(a.val, b.val));

10LRU Cache ↗ MHashMap / Prefix Sum Time O(1) per opSpace O(capacity)
Complete solution (LeetCode signature)
class LRUCache {
    private class Node { int key, val; Node prev, next; Node(int k, int v) { key = k; val = v; } }
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0);   // sentinels: no null checks
    private final int cap;

    public LRUCache(int capacity) {
        cap = capacity;
        head.next = tail; tail.prev = head;
    }
    public int get(int key) {
        Node n = map.get(key);
        if (n == null) return -1;
        unlink(n); addFront(n);                          // mark as most recently used
        return n.val;
    }
    public void put(int key, int value) {
        Node n = map.get(key);
        if (n != null) { n.val = value; unlink(n); addFront(n); return; }
        if (map.size() == cap) {                         // evict least recently used (before tail)
            Node lru = tail.prev;
            unlink(lru); map.remove(lru.key);
        }
        n = new Node(key, value);
        map.put(key, n); addFront(n);
    }
    private void unlink(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void addFront(Node n) { n.next = head.next; n.prev = head; head.next.prev = n; head.next = n; }
}
Key insightHashMap for O(1) lookup + doubly linked list for O(1) reordering. Head side = most recent.
TrapOn put of an existing key, update the value AND move it to the front. Remove the evicted key from the map too.
Follow-upThread safety: one lock around get/put, or LinkedHashMap + synchronized. LFU adds frequency lists.

        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;
        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int size = q.size();                         // nodes on THIS level
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                level.add(node.val);
                if (node.left != null) q.offer(node.left);   // children form the next level
                if (node.right != null) q.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
Key insightBFS with a queue; freeze q.size() before the inner loop so one loop = one level.
TrapReturn an empty list for a null root before touching the queue.
Follow-upRight side view = last of each level; zigzag = reverse every other level; average = sum / size.
12Lowest Common Ancestor of a Binary Tree ↗ MTree DFS Time O(n)Space O(h)
Complete solution (LeetCode signature)
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) return root;      // found one (or nothing)
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);
        if (left != null && right != null) return root;               // p and q on different sides
        return left != null ? left : right;                           // pass the found node upward
    }
}
Key insightPostorder: a node is the LCA when p and q are found in different subtrees (or it is one of them).
TrapThe early return root == p || root == q also covers “p is an ancestor of q”.
Follow-upBST version: walk down: both smaller go left, both larger go right, otherwise this node.
13Number of Islands ↗ MIslands (Matrix Traversal) Time O(m·n)Space O(m·n) recursion
Complete solution (LeetCode signature)
class Solution {
    public int numIslands(char[][] grid) {
        int count = 0;
        for (int r = 0; r < grid.length; r++)
            for (int c = 0; c < grid[0].length; c++)
                if (grid[r][c] == '1') {                 // new island found
                    count++;
                    sink(grid, r, c);                    // erase it so it is counted once
                }
        return count;
    }
    private void sink(char[][] g, int r, int c) {
        if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
        g[r][c] = '0';                                   // mark visited
        sink(g, r + 1, c); sink(g, r - 1, c); sink(g, r, c + 1); sink(g, r, c - 1);
    }
}
Key insightScan every cell; each unvisited land cell starts a flood fill that sinks the whole island.
TrapCheck bounds before reading grid[r][c]. Huge grids can overflow the stack: switch to BFS.
Follow-upMax Area of Island: return a count from the DFS. Not allowed to modify the grid? Use a visited array.
14Course Schedule II ↗ MTopological Sort Time O(V+E)Space O(V+E)
Complete solution (LeetCode signature)
class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) g.add(new ArrayList<>());
        int[] indeg = new int[numCourses];
        for (int[] p : prerequisites) {                  // [a, b]: take b first, so edge b -> a
            g.get(p[1]).add(p[0]);
            indeg[p[0]]++;
        }
        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i);   // no prerequisites
        int[] order = new int[numCourses];
        int idx = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            order[idx++] = u;
            for (int v : g.get(u)) if (--indeg[v] == 0) q.offer(v);           // v is now unlocked
        }
        return idx == numCourses ? order : new int[0];  // fewer than n taken = cycle
    }
}
Key insightKahn's algorithm: start with courses that have no prerequisites; taking one frees its dependants.
TrapEdge direction: [a, b] means b before a, so the edge is b → a.
Follow-upCourse Schedule I only needs the count check. DFS with three colours also detects the cycle.
15Network Delay Time ↗ MGraph Time O((V+E) log V)Space O(V+E)
Complete solution (LeetCode signature)
class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<List<int[]>> g = new ArrayList<>();
        for (int i = 0; i <= n; i++) g.add(new ArrayList<>());          // nodes are 1..n
        for (int[] t : times) g.get(t[0]).add(new int[]{t[1], t[2]});   // directed u -> v, weight w
        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> Integer.compare(a[1], b[1]));
        pq.offer(new int[]{k, 0});                                      // {node, distance}
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int u = cur[0];
            if (cur[1] > dist[u]) continue;                             // stale entry: already improved
            for (int[] e : g.get(u)) {
                int nd = cur[1] + e[1];
                if (nd < dist[e[0]]) { dist[e[0]] = nd; pq.offer(new int[]{e[0], nd}); }
            }
        }
        int ans = 0;
        for (int i = 1; i <= n; i++) {
            if (dist[i] == Integer.MAX_VALUE) return -1;                // unreachable node
            ans = Math.max(ans, dist[i]);
        }
        return ans;
    }
}
Key insightDijkstra from k; the answer is the largest shortest distance, or -1 if a node is unreachable.
TrapNodes are 1-indexed; size arrays n + 1. Skip stale heap entries.
Follow-upCheapest Flights Within K Stops: add the stop count to the state (or Bellman-Ford with K+1 rounds).
16Coin Change ↗ MUnbounded Knapsack Time O(amount · coins)Space O(amount)
Complete solution (LeetCode signature)
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];                  // dp[a] = fewest coins to make a
        Arrays.fill(dp, amount + 1);                     // "infinity" that is safe to add 1 to
        dp[0] = 0;                                       // zero coins make amount 0
        for (int a = 1; a <= amount; a++)
            for (int c : coins)
                if (c <= a) dp[a] = Math.min(dp[a], dp[a - c] + 1);   // use coin c last
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
Key insightUnbounded knapsack: dp[a] = fewest coins for amount a, built from smaller amounts.
TrapUse amount + 1 as infinity (not MAX_VALUE, which overflows when you add 1).
Follow-upNumber of ways (Coin Change II): dp[0] = 1, coins in the OUTER loop, add instead of min.
17Word Break ↗ MUnbounded Knapsack Time O(n · L)Space O(n)
Complete solution (LeetCode signature)
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> dict = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String w : wordDict) maxLen = Math.max(maxLen, w.length());
        boolean[] dp = new boolean[s.length() + 1];      // dp[i]: s[0, i) can be segmented
        dp[0] = true;                                    // empty prefix
        for (int i = 1; i <= s.length(); i++)
            for (int len = 1; len <= Math.min(i, maxLen); len++)
                if (dp[i - len] && dict.contains(s.substring(i - len, i))) {   // last word = s[i-len, i)
                    dp[i] = true;
                    break;
                }
        return dp[s.length()];
    }
}
Key insightdp[i] = can the prefix of length i be segmented. Try every dictionary-sized last word.
TrapOnly try lengths up to the longest word, otherwise you build O(n²) substrings.
Follow-upWord Break II (all sentences): memoised DFS that returns lists.
18Combination Sum ↗ MBacktracking Time O(2^(target/min))Space O(target/min) depth
Complete solution (LeetCode signature)
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);                         // lets us stop early
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, 0, target, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] a, int start, int remain, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }   // record a COPY
        for (int i = start; i < a.length && a[i] <= remain; i++) {      // prune: too big, stop
            path.add(a[i]);                              // choose
            dfs(a, i, remain - a[i], path, res);         // explore (i, not i + 1: reuse allowed)
            path.remove(path.size() - 1);                // erase
        }
    }
}
Key insightBacktracking with a start index; recurse with the SAME index because a number may be reused.
TrapCopy the path when recording (new ArrayList<>(path)) and undo the choice after the call.
Follow-upCombination Sum II (no reuse, duplicates): sort, recurse with i + 1, skip equal neighbours.
19Daily Temperatures ↗ MMonotonic Stack Time O(n)Space O(n)
Complete solution (LeetCode signature)
class Solution {
    public int[] dailyTemperatures(int[] t) {
        int[] res = new int[t.length];                   // default 0 = no warmer day
        Deque<Integer> st = new ArrayDeque<>();          // indices, temperatures decreasing
        for (int i = 0; i < t.length; i++) {
            while (!st.isEmpty() && t[i] > t[st.peek()]) {
                int j = st.pop();                        // day j finally sees a warmer day
                res[j] = i - j;
            }
            st.push(i);
        }
        return res;
    }
}
Key insightMonotonic stack of indices with decreasing temperatures; a warmer day resolves everything colder on the stack.
TrapStore indices, not values, because the answer is a distance.
Follow-upNext Greater Element II (circular): loop 2n times with i % n.
20Find Median from Data Stream ↗ HTwo Heaps Time O(log n) add, O(1) medianSpace O(n)
Complete solution (LeetCode signature)
class MedianFinder {
    private final PriorityQueue<Integer> lo = new PriorityQueue<>(Collections.reverseOrder()); // max-heap, smaller half
    private final PriorityQueue<Integer> hi = new PriorityQueue<>();                          // min-heap, larger half

    public void addNum(int num) {
        lo.offer(num);                                   // 1. go into the small half
        hi.offer(lo.poll());                             // 2. move its largest to the big half
        if (hi.size() > lo.size()) lo.offer(hi.poll());  // 3. keep lo.size() >= hi.size()
    }
    public double findMedian() {
        return lo.size() > hi.size() ? lo.peek() : (lo.peek() + hi.peek()) / 2.0;
    }
}
Key insightMax-heap for the smaller half, min-heap for the larger half; the tops are the middle values.
TrapAlways route a new number through lo then hi so the halves stay ordered; then rebalance sizes.
Follow-upValues only in 0..100? Use a count array. Sliding-window median needs lazy deletion.

  • Reproduce with the smallest failing input
  • Print or trace one variable, not everything
  • Run the checklist: off-by-one, < vs <=, copied the path list?, int overflow, visited marked, missing return, mutated while iterating

  • Narrate in short sentences at each checkpoint: “I am going to ... because ...”; silence reads as being lost.

Back-of-the-envelope

  • QPS = daily active users × requests per user per day / 86,400 (peak ≈ 2–3× average; 1M requests/day ≈ 12 QPS).
  • Storage = daily data × retention × replication factor.
  • Bandwidth = QPS × payload size.
  • Remember: 2^10 ≈ 10^3 (KB), 2^20 ≈ 10^6 (MB), 2^30 ≈ 10^9 (GB).

  • Memory read ~100 ns
  • SSD random read ~100 µs
  • Round trip in same data centre ~0.5 ms
  • Disk seek ~10 ms
  • Cross-continent round trip ~100-150 ms
