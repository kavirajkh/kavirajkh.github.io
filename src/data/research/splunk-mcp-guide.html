0 Start here

The big picture

MCP (Model Context Protocol) is an open standard that lets an AI app call tools that you provide. Claude cannot reach into your Splunk on its own. So you write a small program, an MCP server, that offers a few Splunk-shaped tools. Claude Code decides when to call them.

What your server will offer

ping

Is the server alive? Never touches Splunk.

list_indexes

Which indexes can this token search?

search_splunk

Starts a search and returns a job ID.

get_search_results

Waits for the job and returns the rows.

Why does a search take two calls?

Splunk runs searches as asynchronous jobs. The server mirrors this: one tool starts the job, another collects results. This keeps each call short and avoids time-outs on slow queries.

2 Step 2

Create a Splunk API token

The server logs in with a bearer token, so your password never appears in any config file.

  1. Go to Settings → Tokens → New Token.
  2. Choose a least-privilege user that can read only the indexes Claude should see, and set an audience such as claude-mcp.
  3. Leave Not Before empty. A future date makes the token invalid until then, so it fails with 401.
  4. Click Create and copy the token from the one-time view.

Put it in environment variables for this terminal session:

terminal
export SPLUNK_URL="https://splunk.example.com:8089"
export SPLUNK_TOKEN="<paste-token-here>"

Check that the token works before going any further:

terminal
curl -s -H "Authorization: Bearer $SPLUNK_TOKEN" \
"$SPLUNK_URL/services/authentication/current-context?output_mode=json" | head -c 300
✓
You should see JSON containing your username. A 401 means the token is wrong or expired; a connection error means the URL or port is wrong.

4 Step 4

Write the server

With FastMCP, a normal Python function becomes an MCP tool. Three things in your code are what Claude actually sees:

Create server.py:

server.py
"""A minimal Splunk MCP server built with FastMCP."""

import asyncio
import os
import re

import httpx
from fastmcp import FastMCP

SPLUNK_URL = os.environ.get("SPLUNK_URL", "https://splunk.example.com:8089")
SPLUNK_TOKEN = os.environ["SPLUNK_TOKEN"]  # fail fast if the token is missing

# Reject `index=*`: it scans every index and is slow and expensive.
WILDCARD_INDEX = re.compile(r"\bindex\s*=\s*\*")

mcp = FastMCP(
  name="Splunk",
  instructions=(
      "Call list_indexes first. Always search a concrete index (no index=*). "
      "search_splunk returns a job id; pass it to get_search_results."
  ),
)


def client() -> httpx.AsyncClient:
  return httpx.AsyncClient(
      base_url=SPLUNK_URL,
      headers={"Authorization": f"Bearer {SPLUNK_TOKEN}"},
      timeout=30,
  )


@mcp.tool()
def ping() -> str:
  """Check that the MCP server itself is alive (does not call Splunk)."""
  return "pong"


@mcp.tool()
async def list_indexes() -> str:
  """List the Splunk indexes this token can search."""
  async with client() as c:
      r = await c.get("/services/data/indexes", params={"output_mode": "json", "count": 0})
      r.raise_for_status()
  return "\n".join(e["name"] for e in r.json()["entry"])


@mcp.tool()
async def search_splunk(query: str, earliest: str = "-24h", latest: str = "now") -> str:
  """Start a Splunk search and return its job id (SID).

  The query must name an index, e.g. `index=web_logs status=500`.
  """
  if WILDCARD_INDEX.search(query):
      raise ValueError("Wildcard index searches (index=*) are not allowed.")
  if not query.lstrip().startswith(("search", "|")):
      query = f"search {query}"
  async with client() as c:
      r = await c.post(
          "/services/search/jobs",
          data={
              "search": query,
              "earliest_time": earliest,
              "latest_time": latest,
              "output_mode": "json",
          },
      )
      r.raise_for_status()
  return r.json()["sid"]


@mcp.tool()
async def get_search_results(sid: str, max_results: int = 20) -> str:
  """Wait for a search job to finish, then return its rows as JSON lines."""
  async with client() as c:
      for _ in range(60):  # poll for up to ~2 minutes
          r = await c.get(f"/services/search/jobs/{sid}", params={"output_mode": "json"})
          r.raise_for_status()
          if r.json()["entry"][0]["content"]["dispatchState"] in {"DONE", "FAILED"}:
              break
          await asyncio.sleep(2)
      r = await c.get(
          f"/services/search/jobs/{sid}/results",
          params={"output_mode": "json", "count": max_results},
      )
      r.raise_for_status()
  return "\n".join(str(row) for row in r.json()["results"])


def main() -> None:
  mcp.run(transport="stdio")


if __name__ == "__main__":
  main()

Design choices worth understanding

ChoiceWhy
instructions= on the serverSent to Claude on connect, so it learns the workflow (list indexes, then search) without you repeating it each time.
Block index=*All-index searches are slow and may touch data Claude should not see. Put guardrails in the server, not only in a prompt.
Two tools for one searchMatches Splunk's async job model and avoids one long blocking call.
Read-only operationsThe server cannot modify Splunk data. Add write tools later, deliberately.
Token from the environmentSecrets stay out of source control.
!
Never print() in a stdio server. With stdio, stdout is the protocol channel. Stray output corrupts messages and the connection drops. Log to stderr or a file.

6 Step 6

Connect it to Claude Code

You tell Claude Code how to start your server. It launches the command, performs the MCP handshake, and lists the tools.

Option A: one command (recommended)

terminal, run from the project folder
claude mcp add splunk \
--env SPLUNK_URL="$SPLUNK_URL" \
--env SPLUNK_TOKEN="$SPLUNK_TOKEN" \
-- uv --directory "$(pwd)" run server.py

Everything after -- is the command Claude Code runs to start your server. Pick where the config lives with --scope:

Option B: a .mcp.json file

Create it in the project root. Claude Code finds it automatically and asks you to approve it the first time.

.mcp.json
{
"mcpServers": {
  "splunk": {
    "type": "stdio",
    "command": "uv",
    "args": ["--directory", "/absolute/path/to/splunk-mcp", "run", "server.py"],
    "env": {
      "SPLUNK_URL": "${SPLUNK_URL}",
      "SPLUNK_TOKEN": "${SPLUNK_TOKEN}"
    }
  }
}
}
✓
${VAR} is expanded from your shell environment, so the token is not written into a file you might commit.

8 Next

Going further

Patterns used by production-grade Splunk MCP servers, ready to add once the basics work.

Multiple environments

Read SPLUNK_TOKEN_PROD, SPLUNK_TOKEN_STAGING… and add an instance argument to each tool.

Typed configuration

Use pydantic-settings for validation, .env loading and CLI flags like --verbose.

Tool allow-list

Let operators enable only some tools, e.g. SPLUNK_ENABLED_TOOLS=list_indexes,search_splunk.

Read-only hints

@mcp.tool(annotations={"readOnlyHint": True}) tells clients a tool is safe.

Retries with backoff

Use tenacity; retry only on 500/502/503/504 and honour Retry-After.

Result limits

Cap rows and strip internal fields (_bkt, _cd…) to save tokens.

HTTP transport

mcp.run(transport="http", host="127.0.0.1", port=8000) to share one server. Keep it local or behind an authenticating gateway.

Query templates

Store vetted, parameterised SPL (e.g. error analysis by service) as JSON and expose it as a tool.

9 Important

Security checklist

  • Use a dedicated, least-privilege Splunk user and token for the server.
  • Give the token an expiry and rotate it.
  • Keep tokens in environment variables or a secret manager. Never commit .env.
  • Keep tools read-only unless you truly need writes.
  • Block expensive patterns (index=*, leading-wildcard-only searches) inside the server.
  • Remember that log content is sent to the model. Logs can contain personal or confidential data, so check your organisation's data-handling rules and limit the indexes the token can read.
  • Review tool-call approvals in Claude Code instead of blanket-allowing everything.
10 Help

Troubleshooting

Start with claude mcp list. Then find your symptom:

“Failed to connect” in claude mcp list

Your start command is crashing. Copy the exact command after -- and run it in a terminal to see the real error.

KeyError: 'SPLUNK_TOKEN'

The environment variable did not reach the server. Add --env SPLUNK_TOKEN=… or fix the env block in .mcp.json. Confirm your shell exported it first.

401 Unauthorized

Wrong token, expired token, or a future Not Before date. Recreate the token and copy the one-time value.

403 Forbidden

The token's user lacks the search capability or index access. Adjust the user's role in Splunk.

SSL: CERTIFICATE_VERIFY_FAILED

Self-signed or private-CA certificate. Trust your CA with httpx.AsyncClient(verify="/path/to/ca.pem"). Avoid verify=False outside local testing.

Connection refused / time-out

Wrong host or port, or a firewall/VPN. Use the management port 8089, not the web port 8000.

Search returns zero rows

Check the time range and the index name. Field names are case-sensitive, field values are not. Try a wider earliest.

Tools are missing after I changed the config

Restart Claude Code, or run /mcp and reconnect the server.

Connection drops right after starting

Something wrote to stdout. In stdio mode, never print(); log to stderr or a file.
